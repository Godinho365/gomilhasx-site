Quem junta milhas em mais de uma conta logo perde o controle: quanto tem em cada programa, o que vence primeiro e quanto cada milha custou. Um app de milhas, ou gerenciador de milhas, resolve parte disso. Mas cada um resolve uma parte diferente. Este comparativo mostra seis opções lado a lado. Uma delas, o GO Manager, é nossa, e a gente diz isso logo aqui para você ler o resto sabendo.

O que um bom controle de milhas precisa mostrar

  1. Saldo e validade de cada conta, por titular e por programa.
  2. Custo do milheiro de cada conta, recalculado a cada compra, transferência ou bônus. Sem ele, não dá para saber se uma venda ou emissão deu lucro. Veja como calcular o custo do milheiro.
  3. Histórico do que entrou e saiu, para conferir depois.
  4. Vendas e lucro, para quem vende milhas ou emite para clientes.

Quem só junta pontos para viajar precisa dos dois primeiros. Quem vende milhas ou emite para clientes precisa dos quatro.

Qual escolher

  • Junta pontos só para viajar, com poucas contas: uma planilha ou um app de celular gratuito costuma bastar.
  • Usa programas estrangeiros: o AwardWallet é o mais conhecido nesse caso.
  • Quer o imposto de renda organizado junto: vale olhar o Iddas, que destaca isso.
  • Compra milhas para vender ou emitir para clientes: o que mais pesa é o custo do milheiro por conta e o lucro de cada venda. Compare Meu Milheiro, Iddas e GO Manager nesse ponto, de preferência com o teste grátis de cada um.

Planilha ou gerenciador de milhas?

A planilha funciona enquanto você lembra de atualizar tudo. Com vários titulares e programas, um esquecimento muda o custo médio e, com ele, o lucro que você acha que teve. Um gerenciador de milhas faz essas contas a cada lançamento. Se estiver na dúvida, comece pela planilha e troque quando ela começar a dar trabalho. A página de controle de milhas compara as duas formas em detalhe.

Por que fizemos o GO Manager

O GO Manager nasceu da operação do fundador, que vende milhas há mais de 3 anos e precisava saber o custo de cada conta antes de responder um cliente. O plano Pessoal é grátis, sem cartão, para 1 titular e até 5 contas. Se ele não for o melhor para o seu caso, qualquer uma das opções acima já é melhor do que não controlar.
